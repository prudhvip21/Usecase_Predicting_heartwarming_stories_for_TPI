# Predicting Heartwarming News Stories

Identify positive, heartwarming stories from large volumes of Indian news so they can be surfaced automatically.

## Approach

- Scrapers and crawlers for The Better India, Indian Express, Times of India and other sources
- Text cleaning and feature extraction, including part-of-speech features
- Exploratory analysis with clustering and topic modelling (KMeans, DBSCAN, LDA)
- Classification with Logistic Regression, SVM, Decision Tree, KNN and Naive Bayes on TF-IDF features

## Results

SVM accuracy of about 0.82 in the saved notebook output.
